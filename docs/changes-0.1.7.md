# 0.1.7 翻页、收藏下划线与连字符查词

- 点击右侧空白页边翻下一页，点击左侧空白页边翻上一页。页边操作仅限正文区域；点击到单词仍优先查词，不会翻页。中部空白继续控制工具栏显示。
- 短距离横向轻扫可翻页：至少 28 CSS 像素、横向位移大于纵向位移的 1.5 倍、时长不超过 650 毫秒。上下移动、长按、多点触摸和选中文字不会按普通翻页处理。一次手势只翻一页，滑动后的点击不会误查词。
- 页边、轻扫、音量键和底部按钮使用统一翻页入口与翻页锁。页内过渡约 180 毫秒；跨章节以 70 毫秒淡出和 110 毫秒淡入衔接，避免先翻到空白占位页。到全书首尾会轻量提示。
- 阅读设置中“翻页动画”默认开启，可关闭；遵循系统减少动态效果设置。
- 收藏词默认以细下划线标记。通过随包 SQLite 词典的词形表识别常见规则和不规则变化，例如 notice → noticed / noticing，go → went / gone；有多个原形且无法确定时不自动扩展标记。阅读设置中的“收藏词下划线”可关闭。
- 下划线由阅读引擎的独立覆盖层绘制，只处理当前可见文字，不插入或修改书籍正文，保留 CFI 阅读定位、长按选择与复制。收藏增减、换页、字号及背景变化后刷新。
- 连字符组合按点击部分查询，例如 well-known 中点击 well 查询 well，点击 known 查询其词条/原形。原句只突出对应部分，保留“查询完整词”可选入口。英文撇号词如 don't 仍按整体查询；兼容常见 Unicode 连字符。

验证：核心及生词数据测试；浏览器手机测试页边左右点击、短距离轻扫、纵向手势拒绝、词语点击优先、连字符两个部分及完整组合查询、规则/不规则词形下划线、正文未改变、动画/下划线开关、跨章节实际动画调用；回归阅读查词、发音、收藏、书签、主题、导入及离线合成。Android 15 模拟器验证原生词形查询、正文真实触摸、页边翻页、连字符查词、下划线显示及音量键翻页，确认阅读定位稳定。Android 构建与 lint 通过。小米 15 / HyperOS 真机仍需安装复测。
