# 0.1.6 生词本发音及菜单修复

- 生词本右侧的喇叭直接播放单词读音，沿用在线真人、本地真人、离线合成的原有选择逻辑；不再查询词典、打开查词卡或改变列表滚动位置。加载、播放状态显示在所点击的喇叭图标上，保留无障碍名称。
- 快速切换不同单词时停止前一个发音，过时的录音请求不会覆盖最近点击的单词。
- 修复三个点按钮读取错误属性的问题：原先读取 `data-word`，按钮实际使用 `data-word-menu`，导致找不到单词而无法打开菜单。现在菜单正确对应所点击的词条，提供设置标签、查看释义与原句、取消收藏。

验证：浏览器手机触摸测试覆盖真人录音、离线合成、无查词请求/无弹窗/无滚动、快速切换、每个词条的菜单、标签保存、查看详情、取消收藏及重载持久化；回归阅读页查词、发音、收藏、书签、主题及导入。Android 构建和 lint 通过。Android 15 模拟器以原生触摸事件验证直接发音及词条菜单各项入口。小米 15 / HyperOS 真机仍需安装复测。

安装 `outputs/leaf-reader-0.1.6-debug.apk` 可直接覆盖安装，保留书架、生词、标签与设置。
