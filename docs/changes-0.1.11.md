# 0.1.11 每日短语排版与每日风景

- 每日短语按实际文字宽度与卡片宽度调整字号：能在不低于 22px 的情况下完整显示时保持一行；较长短语采用自然换行，不裁切、不省略内容。原本 28px 的标题不会为了单行被无限缩小。
- 内置 8 张原创 SVG 自然风景插画，包含湖泊、山峦、海岸、林谷和田野等，按本地日期每日轮换。全部图片约 15.3 KiB，离线可用，不请求外部图片服务，不引入照片授权来源。
- 背景与短语同在跨午夜、重新打开首页和后台返回时更新；同一天不随机更换，8 天一轮。
- 卡片使用白色文字和深色遮罩，夜间加深背景，保留中英文释义及例句的可读性。
- 版本号 0.1.11，versionCode 12，保留已有应用签名与存储格式。

验证：核心测试、首页分离／跨天刷新测试，以及每日卡片专项测试通过。专项测试验证 320／393／760px 下截图所示短语 `find common ground` 保持一行；全部 60 条短语在 320px 下无横向溢出；全部 8 张图片离线解码成功；跨午夜、重载、返回首页的图片切换正确，过程中没有外部网络请求。日间和夜间截图已人工检查。Android 构建、lint、签名及 APK 内资源哈希检查通过。

安装文件：`outputs/leaf-reader-0.1.11-debug.apk`，可覆盖此前个人测试版。本轮未连接小米 15 真机，实际系统字体缩放和 WebView 下的显示仍需安装后确认。图片是轻量风景插画，并非每日联网下载的新照片。
