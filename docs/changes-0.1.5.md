# 0.1.5 生词本整理

生词本默认按最近收藏显示全部单词，支持按书籍、标签及搜索内容组合筛选，也可改为字母排序。

- 列表显示单词、音标、发音图标、简短释义、标签和书籍来源，完整释义及原句在单词详情查看。“展开原句”可在列表中显示最近一条原句，选择会保存。
- 收藏自动记录书籍来源；原书删除后仍保留书名及原句。没有来源的旧条目可在“无书籍来源”筛选中找到。
- 单词支持多个标签。未加标签的词可用“未分类”筛选。标签可新建、重命名及删除，删除标签不会删除单词。
- 点“整理”或长按词条进入多选；支持全选当前结果、批量添加标签、移除标签及取消收藏。切换筛选或搜索会清空选择，避免操作隐藏条目。取消收藏需确认。
- 同一个词在不同原句中出现时，点击星标会追加新原句，合并在一个词条下，并保留原有标签。新语境的星标显示为空心；已保存的语境显示实心。
- 详情中“其他遇见记录”可查看不同语境，原书仍在书架时可返回原文。取消收藏含多条原句的词会再次确认。
- 兼容旧版单个原句的数据；迁移后保留原句、书籍来源、阅读定位及收藏时间。新标签及全部原句随本地 ZIP 备份导出和恢复，所有整理功能均离线可用。

## 验证

- 数据测试：旧数据迁移及重复迁移、词条合并、词形保留、标签与组合筛选、删除原书后的来源、序列化恢复。
- 浏览器：书籍/标签/未分类筛选、排序、精简释义、原句开关、长按多选、批量标签、新建/改名/删除标签、真实阅读点击后合并原句、多原句取消确认、缺失原书提示、页面重载、实际 ZIP 导出恢复、320px 布局和夜间模式、批量取消收藏。
- 回归：阅读、查词、发音、收藏、书签、主题和粘贴导入；查词图标及原句高亮、小屏横屏布局。
- Android 15 模拟器：从旧版覆盖升级后保留书架与旧生词，批量标签写入原生存储，真实正文点击追加原句，重新加载后数据保留，原生触摸长按进入多选。
- Android 构建和 lint 通过。小米 15 / HyperOS 真机仍需安装复测。

安装 `outputs/leaf-reader-0.1.5-debug.apk` 可覆盖之前版本，保留已有书架、生词和设置。安装包约 37.4 MB。
