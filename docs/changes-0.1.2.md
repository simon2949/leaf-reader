# 0.1.2：阅读首页与独立书架

## 页面与书籍卡片

- 默认进入「阅读」页：继续阅读最近打开的书籍，并展示每日短语。无阅读记录时提供第一本书的入口；空书架时提供前往书架的入口。
- 「书架」独立，保留书籍、作者、格式、进度、搜索、导入和管理。
- 底部导航为「阅读 / 书架 / 生词本 / 设置」。从正文返回到进入正文之前所在的页面。
- 去掉书籍卡片的 LEAF LIBRARY、YOUR OWN PAGES、CONTINUE READING 等装饰文案；隐藏旧示例书的品牌作者占位信息。真实书籍的书名和作者保留。
- 顶部使用页面名称，移除阅读页和书架页的品牌横幅、口号和词典状态文案。

## 每日短语

内置 60 条常用表达，配中文释义、原创英文例句和例句翻译。根据手机本地日历日期选择，每天轮换，无需联网或额外下载。一个轮换周期内不重复，之后循环。

同一天重新打开仍为同一条；页面打开时在本地午夜更新，应用从后台回到前台或重新获得焦点时也会检查日期。只更新短语卡片，不重置阅读位置、书架搜索或生词数据。没有添加账号、远程定时任务、后台服务或网络短语接口。

## 验证

- 日期单元测试：同日稳定、午夜切换、月底／年底边界、60 条轮换不重复。
- 浏览器手机视口：独立页面、无装饰品牌文字、搜索、继续阅读和返回页；模拟上海时区跨零点、重新打开和回到前台更新。
- 阅读回归：正文打开、查词、英汉／英英切换、真人发音、收藏持久化、书签、主题和粘贴文章导入。
- Android 15 原生 WebView，1200×2670、手势导航：阅读页和书架截图核对，最近书籍继续阅读与返回，书籍和 quiet 收藏在覆盖升级后保留。
- Gradle assembleDebug 与 lintDebug 通过。原生截图在 `outputs/android-0.1.2-home.png` 和 `outputs/android-0.1.2-library.png`。

安装包为 `outputs/leaf-reader-0.1.2-debug.apk`，versionCode 3，沿用原包名和签名，可直接覆盖安装。持久化数据结构仍为 version 1，不需要迁移或重新导入书籍。仍需小米 15 / HyperOS 真机复测。
