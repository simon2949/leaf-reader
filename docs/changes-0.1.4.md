# 0.1.4 字体、对齐与音量键翻页

阅读页右上角 Aa 或“设置 → 字体与背景”可使用以下选项，修改即时生效，并随本地设置及备份保存。

- 7 种离线字体：Noto Serif、Noto Sans、Liberation Serif、Liberation Sans、DejaVu Serif、DejaVu Sans、Liberation Mono。保留实际字体名称，不把开放字体标成 Arial、Times New Roman 等商业字体。常规字形随 APK 内置，不需联网或下载系统字体；粗体和斜体由浏览器合成。
- 字体下方可预览文字。原有字号、行距、页边距和背景设置保留。
- 正文支持左对齐、两端对齐、居中和右对齐。
- “音量键翻页”默认关闭。开启后，阅读正文时音量减翻下一页，音量加翻上一页；长按只翻一页，避免快速跳过内容。
- 设置、查词等面板打开时，退出阅读、选中文字或应用在后台时，不接管音量键。翻页操作不会调整媒体音量。

验证：浏览器确认七种字体实际加载并在禁止外网请求时可用；验证四种对齐、设置重载保存、开关与面板行为、320px 布局，并回归查词、收藏、发音、书签和主题。Android 15 模拟器中确认全部字体加载、真实音量上下键事件、长按单次翻页、音量不变、面板和开关阻止翻页。Android 构建与 lint 通过。小米 15 / HyperOS 真机仍需安装复测。

可用 `outputs/leaf-reader-0.1.4-debug.apk` 覆盖安装，保留已有书架、生词及设置。
