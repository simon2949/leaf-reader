# 0.1.9 字体选项显示字形

- 阅读设置移除独立的字体示例句及预览区，保留“英文字体”选择。
- 当前选中的字体名称，以及展开列表中的七个字体选项，直接使用各自对应的内置字体显示。列表使用应用内控件，避免 Android 系统原生选择器统一显示成系统字体。
- 选择后立即应用到正文，并保留本地保存、夜间配色、离线字体和键盘操作。

验证：手机尺寸浏览器确认无示例句、七种实际字体资源加载、选项与当前字体名称的字形、正文应用、重载保存、键盘选择、小屏与夜间布局。Android 构建与 lint 通过。小米 15 真机仍需覆盖安装后复测。

安装 `outputs/leaf-reader-0.1.9-debug.apk` 可覆盖前版，保留书架、生词、标签与设置。
