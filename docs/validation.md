# 验证记录

## 真人录音移除（2026-10-30，v0.1.13）

当前资源清单仅保留 70 个文件，原内置的 3,002 个 Ogg 录音、Shtooka 索引与许可副本均已移除；删除旧整包导入脚本。资源检查要求内置录音数量和字节数为 0，字典仍为 401,818 条，合成核心及美音数据的来源哈希检查保留。

Java 回归覆盖版本明确的 CC BY / BY-SA、CC0、公有领域，以及不完整署名、矛盾链接、未知许可、NC / ND 和错误来源的拒绝。浏览器使用测试临时生成的 WAV 检查录音播放、快速切换与菜单交互，生产资源没有这些样本；无录音时实际合成产生非空 WebAudio。浏览器不访问 Commons，因此这些测试不代表所有手机网络都能下载真人录音。网络限流、超时和覆盖缺失均回退合成。

最终 APK 为 28,488,358 bytes，与前版签名一致，全部 70 个资源逐字节匹配当前源码且无 Ogg／FLAC。Android 构建与 lint、17 项核心测试、浏览器全套及新增署名回归、96 次合成等价、格式／备份、Java 策略均通过。真实 Commons 样本 adventure 的逐条许可通过生产 AudioPolicy，Ogg 下载成功；该联网检查运行在主机，并不替代小米真机端到端测试。见 [证据](audio-removal-evidence.json)。

历史处置更新：原仓库及旧 APK 隔离到私有归档，新公开仓库仅包含经过检查的当前快照。见 [公开记录](public-release.md)。原 CI 链接属于改名前的历史记录；新仓库重新运行全部 CI。

## 核心与浏览器流程

- 文本处理：英文连字符／所有格点击范围、标点边界、TXT 多章节和前言保留、原句提取、HTML 转义、备份基本格式校验。
- `tests/e2e.cjs`：演示书打开，实际坐标点击 quiet，英汉／英英切换，播放真人美音，收藏与重载持久化，书签，夜间模式，粘贴文章导入。无未捕获页面异常。
- `tests/mobile.cjs`：真实触摸事件左右滑动，进度从 14% 变为 29%；阻止所有外部网络请求，sesquipedalian 使用内置离线合成；没有外部资源请求。
- `tests/formats.cjs`：自创 EPUB 样本、未压缩 MOBI 样本、目录、ZIP 含书籍备份与恢复；EPUB 中的脚本不能设置宿主标志。
- 额外样本：上游 [libmobi 测试目录](https://github.com/bfabiszewski/libmobi/tree/public/tests/samples) 的 `sample-obfuscated-fonts.mobi`（MOBI v8 / KF8）及 `sample-unicode-huffdic.mobi` 能显示正文；带 DRM 样本拒绝导入。这些外部样本仅用于临时验证，没有打包进 App。

## 仍需真机验收

浏览器验证覆盖共用的阅读与交互代码，但不能替代 Android 原生桥接测试。仍需在实际 Android 手机上检查：

- 首次安装、WebView 版本兼容、首次词典初始化、文件选择器导入。
- 扬声器／耳机、断网、网络切换、真人音频服务失败后的回退。
- 系统返回、旋转、后台、进程回收后阅读进度保存。
- Android SAF 导出、原生 ZIP 恢复，以及大文件和不同厂商系统的行为。
- 用户实际持有的 EPUB／MOBI／AZW／AZW3 书籍排版兼容性。

因此此 APK 定义为可安装的功能测试版，不是已经完成真机验收的正式上架版。
