# 叶读 v0.1.13 · 移除内置真人录音包

本版按所有者要求，移除无法统一核清许可的内置真人录音包，共 3,002 条、8,177,272 bytes。安装包不再附带真人录音，也移除旧集合索引、许可副本和整包导入脚本。

发音顺序为：许可署名完整的已有真人缓存 → 联网获取真人美音 → 内置离线美音合成。下载保留作者、来源、许可和许可链接，原样缓存；缺少录音或许可资料、下载失败和离线无缓存时均可合成。已有缓存也检查许可与来源。设置中的资源说明和署名界面同步更新。

版本号 0.1.13，versionCode 14。沿用原开发测试签名和数据格式，可覆盖安装；无需卸载或清除数据。手机安装前可先从设置导出备份。新版本的安装文件与校验文件见本 Release 的 Assets，Source code ZIP 是源码，不是安装包。

源码按 GPL-3.0-only；离线合成引擎源码、数据源及许可继续随项目保留。本 Release 为公开开发测试版；旧 Git 历史和旧测试包保存在单独的私有归档，不属于公开仓库。公开历史从当前无录音版本开始。
