# 0.1.8 底部阅读菜单与亮度

- 阅读时默认隐藏工具栏，底部保留低调的章节/进度入口；轻点正文中部空白或底部进度可显示菜单。左右空白页边翻页、单词查词、音量键翻页继续保留。
- 顶部保留返回、书名和书签。底部为“目录、日间/夜间、设置”，上方显示章节、阅读百分比、进度滑块及上一章/下一章。翻页使用原有页边/滑动/音量键；底部的上一章/下一章明确按章节跳转。
- 工具栏及目录/设置面板覆盖于正文之上；显示、收起时阅读区域尺寸不变，不重新分页。目录/设置展开时底部三项入口仍可点击，并显示当前打开项。
- 目录自动定位当前章节，并显示当前项；书签页可返回已保存的位置。通过目录或章节按钮跳转后收起菜单。
- 进度滑块拖动时仅预览百分比，松手才跳转，避免拖动中连续跳页。
- 日间为浅色背景、黑色正文；夜间为纯黑背景、纯白正文。中间按钮显示可切换到的模式，日间恢复上次纸张或明亮背景；系统栏颜色和图标随之更新。
- 设置面板优先显示亮度、七种字体及预览、字号减小/增大、背景。行距、页边距、对齐、音量键、动画和收藏下划线收在“更多设置”中。
- 亮度默认跟随系统；滑动亮度条切换为手动模式，范围 5%–100%。使用 Android 窗口亮度，不修改系统亮度，也不需要修改系统设置权限；应用进入后台恢复系统亮度，回来后恢复手动设置。选择随本地备份和设置保存。

验证：核心与生词数据测试；浏览器验证菜单及面板展开/收起时视口和 CFI 定位不变、底部导航可切换面板、当前目录/书签、章节切换、进度预览和提交、黑白日夜配色、亮度 UI 与重载保存、字号按钮、更多设置、320px 布局。回归七种离线字体、四种对齐、音量键开关、查词、收藏、发音、书签、主题及粘贴导入。Android 15 模拟器真实触摸验证底部入口、目录及设置切换、视口与定位稳定、窗口亮度 35%、系统亮度值不变、跟随系统、后台恢复及回到 App 后恢复手动亮度、纯黑白夜间正文及系统栏显示。构建与 lint 通过。小米 15 / HyperOS 真机仍需覆盖安装后复测。
