# 0.1.1：正文空白与系统栏重叠修复

用户在小米 15 上反馈：《麦琪的礼物》MOBI 以及自带 TXT 均不显示正文，顶部后退／书签／字体按钮与状态栏重叠。

## 修改

- WebView 导航检查允许可信本地源生成的 Blob 正文子页面，以及子页面初始 about:blank。以前将它们当成外部导航取消，导致所有格式正文空白。主页面不能跳转到 Blob，其他源及 file/javascript 等导航继续阻止。
- 用原生 FrameLayout 容器处理系统栏、显示挖孔和输入法边距，实际缩小 WebView 视口。修复只给 WebView 加 padding、没有约束 HTML 固定定位工具栏的问题。横竖屏及手势导航使用系统返回的边距，不硬编码状态栏高度。
- 阅读引擎在子页面尚未加载、尺寸为零或页面已销毁时不执行排版；清理 ResizeObserver 和异步字体／样式回调，避免 MOBI 加载时空文档重排异常。
- 加载失败或超时会返回错误，不再一直停在没有提示的空白页。翻页失败后解锁导航，允许再次操作。
- MOBI 段落默认左对齐，避免原书两端对齐在手机窄屏上拉大词间距。
- 版本号 0.1.1（versionCode 2），包名及开发签名沿用 0.1.0，可覆盖安装。

## 回归验证

- 导航策略 JVM 断言：放行本地正文子页面，拒绝外部源、伪造同源、文件和脚本导航。
- 全部 12 份官方故事样本在浏览器阅读器中重新通过导入、加载和翻页检查，包括《麦琪的礼物》MOBI。
- 自带 TXT、点击查词、英汉／英英、真人美音、收藏持久化、书签、背景设置及文章导入检查通过。
- Android 构建与 lint 通过，报告 `No issues found.`。
- Android 15 原生 WebView、1200×2670、手势导航：旧版复现为正文 `about:blank`、无文本，CSS 视口占满 890 dp；新版正文为可信 Blob 页面，有实际文字，原生容器使视口高度变为 816 dp。
- 原生 WebView 实测边界 `[0,151][1200,2598]`，避开上方系统栏及下方手势区。实际像素边距由设备系统提供，不是 App 硬编码。
- 新版自带 TXT、MOBI 正文、翻页（6% → 8%）、点击 moral 查词、本地 SQLite 查询均通过。横屏重排后视口 840×348 dp，正文与工具栏仍正常。
- 从旧版直接覆盖升级到新版，旧书架和 quiet 收藏保留。截图及验证数据在 `outputs/android-0.1.1-*`。
- 仍需小米 15 / HyperOS 真机复测；模拟器不能代表全部厂商系统行为。

## 安装

覆盖安装新 APK 后直接打开原有书籍，无需删除原书。若系统要求卸载旧版，请先停止操作并备份数据；正常同签名更新应保留书架和生词。


原生回归入口：在已预载自带 TXT 和官方《麦琪的礼物》MOBI 的调试模拟器上，将 WebView DevTools socket 转发至本机 9222，然后运行 `node tests/android-reader.cjs`。此测试使用真实 Java bridge 和原生文件服务，不使用浏览器存储适配器。导航策略测试可用 JDK 直接编译执行 `tests/NavigationPolicyTest.java`。
