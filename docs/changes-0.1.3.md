# 0.1.3 查词卡优化

- 发音和收藏改为单词标题右侧的纯图标，删除独立按钮行及播放说明。点击区域保持至少 44 × 44 CSS 像素，保留无障碍名称、播放状态和收藏状态。
- 原句移到释义上方，以更大的字号、正常字体及高对比度卡片展示。查询词使用底色、加粗和下划线突出；收藏回看同样高亮。
- 高亮使用书中遇到的词形，例如查 went、词典返回 go 时，原句仍高亮 went。按完整单词匹配并转义导入内容，避免误标词内子串或插入 HTML。
- 点击收藏不再重绘整张卡片，原句、释义滚动位置及发音不会被打断。真人录音署名仍可在设置中的“关于与开源资源”查看。

验证：核心单元测试、浏览器阅读/查词/收藏/发音回归、完全阻断外网后的离线合成与滑动翻页、320px 小屏/横屏/夜间/长单词/未收录单词布局。Android 15 模拟器覆盖安装后验证图标与原句高亮；Android 构建和 lint 检查通过。小米 15 真机效果仍需安装复测。

安装 `outputs/leaf-reader-0.1.3-debug.apk` 可覆盖此前版本，保留书架、生词与设置。
