# 0.1.10 生词本筛选与标签快捷入口

- 书籍、标签和排序不再弹出 Android 原生单选框，改用应用内底部选择面板，沿用页面背景、圆角和绿色选中标记。夜间配色同步跟随应用。
- 选项较多时提供搜索；支持“全部书籍”“无书籍来源”“全部标签”“未分类”。长名称可换行，筛选按钮中的长名称省略显示。
- 每个单词右下角增加“＋ 标签”快捷按钮，直接打开标签选择，保留已选标签，可选择多个标签及新建标签。点击保存后立即更新，关闭面板不会提交未保存的勾选变化。
- 标签选择改成紧凑的可多选标签块。新建标签会立即加入标签目录，单词的标签变更仍需保存。
- 保留三个点菜单和批量整理；整理模式下隐藏单词的标签快捷入口，避免与批量操作混淆。
- 数据格式不变，保留已有书籍、生词、标签、原句和设置。

## 验证

- 核心测试、资源哈希和 SQLite 检查通过。
- `vocabulary-ui`：筛选、排序、长按、批量标签、标签管理、多来源原句、备份恢复与取消收藏通过。

- Android `assembleDebug` 和 `lintDebug` 通过，lint 无问题。
- APK 内 3,066 个资源与已测试源码哈希一致，签名校验通过；开发证书与 0.1.9 相同。versionCode 从 10 升至 11。
