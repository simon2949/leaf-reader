# 叶读 Leaf：最初的产品约定

这是 0.1.0 阶段的历史约定。当前功能以根目录 README 和 CHANGELOG 为准。

Android 个人英文阅读器，无账号、无广告、本地存储。

- 导入无 DRM 的 TXT、EPUB、MOBI、AZW、AZW3；网页链接联网提取正文后保存；支持粘贴文章。暂不支持 PDF。
- 左右滑动翻页；目录、书签、进度跳转、自动保存阅读位置；字号、行距、页边距、纸张／明亮／夜间背景。
- 单击单词打开底部卡片，查询原形、音标、英汉／英英释义。长按文本使用系统选择和复制。
- 美音优先：已有真人缓存直接播放，否则联网请求真人录音；断网无缓存、录音缺失或请求失败时使用内置美音合成。安装包不附带真人录音；合成引擎首次使用无需下载。
- 一键收藏，保存原句、书籍来源与阅读位置；支持搜索、回看、读音、取消收藏和返回原书。删除原书保留生词及原句。
- 本地 ZIP 备份与恢复，书籍可选；支持只备份元数据后重新导入原书并恢复关联。

暂不包含短语词典、整句翻译、语境解释、全文朗读、笔记标注、复习计划和云同步。

安装体积优先，第一版使用小型 eSpeak 美音合成。它是合成声音，偏机械；不将合成内容标为真人录音。词典音标沿用 ECDICT 数据，不保证是美式音标。
